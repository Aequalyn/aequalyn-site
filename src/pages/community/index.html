The rules

The same everywhere we meet: on Discord, on Reddit, in issues and in the Market.

  • Be kind. No harassment, insults or hate, about anyone, for any reason.
  • Help, don't gatekeep. Everybody started somewhere; answer the question that was asked.
  • No malware, no piracy. Nothing that hides what it does, takes what is not yours, or ships fonts, pictures or code without the right to.
  • No spam. Share what you made where it fits, once; no ads, no referral links.
  • Credit what you build on. Say where wallpapers, icons and code come from, with their license.
  • Security problems go privately to the maintainers, not into a public thread, so they can be fixed first.

Moderators may remove what breaks them, and remove whoever keeps breaking them.

Publish in the Market

  1. Read the guidelines for what you made: plugin, theme, cursor, wallpaper pack, look or app.
  2. Name its repository after it (below) and put it on GitHub.
  3. Run the checks the bot runs: aequalyn-store check <kind> . --market.
  4. Open an issue with the Publish form for its kind. The bot pins the commit, checks it and posts a report.
  5. A reviewer reads it. Approved, it goes into the catalog at that exact commit, and every Store offers it.

A Store installs only the commit that was reviewed. To update, push the new version and open the Update form: until it is reviewed too, what you pushed reaches nobody.

Repository names and ids

An item's id is the name the Store installs it under, so no two may be mistaken for each other. So the repository carries the id:

KindRepositoryId
Pluginaequalyn-plugin-dev-statsdev-stats
Themeaequalyn-theme-lichenlichen
Cursoraequalyn-cursor-facetfacet
Wallpaper packaequalyn-wallpapers-lichenlichen
Lookaequalyn-look-lichenlichen
Appaequalyn-app-nudunudu
  • An id is lowercase letters and digits with single dashes between them, up to 40 characters.
  • It is not one of Aequalyn's own: the shell's plugins, the built-in themes, wallpapers, cursor and looks, nor aequalyn, official, builtin, default, system or core.
  • It does not read the same as another repository's id of the same kind: dev-stats, devstats and dev.stats are one name, and the first to publish it keeps it.
  • Two kinds may share a name: theme:lichen and look:lichen.
  • Once in the catalog, an id never changes, and only who published it, or owns its repository, can update it.

The bot checks all of this before a person reads anything; the Market's README has the details.
