# Getting help

## Something does not work

- **Look it up here first.** The search box in the sidebar searches every page of the
  documentation.
- **Repair from the live ISO.** Boot the Aequalyn ISO and run `aequalyn-repair`: it can
  refresh the installed system's keyring, reinstall its kernel or bootloader, or open a
  shell inside it. See [Install from the ISO](/docs/install/).
- **Update.** Many problems are already fixed in the newest code: see [Updating](/docs/updating/).

## Ask, or report it

Open an issue on GitHub in the repository the problem belongs to
([which one?](/docs/contributing/#report-a-problem)). For anything else, the
[contact page](/contact/) reaches the team.

## Something in the Market

An item from the Market belongs to its author: open an issue on that item's repository,
linked from its page in the [Market](/market/). To report an item that breaks the
guidelines, open an issue in [aequalyn-market](https://github.com/Aequalyn/aequalyn-market/issues).
