# Introduction

Aequalyn is a desktop for Arch Linux. It is made of a few parts that you can use together,
as the Aequalyn ISO installs them, or one by one:

- **the core** (`aequalyn`): the commands, the Hyprland configuration, the installer of the
  desktop into a home, and the migrations that carry every install along with each update;
- **the shell** (`aequalyn-shell`): the Quickshell desktop itself, its bar, docks, control
  center, Store and Atelier;
- **the themes** (`aequalyn-themes`) and **the Market** (`aequalyn-market`), where everything
  else that you can install comes from;
- **the ISO** (`aequalyn-iso`), **the installer** (`aequalyn-installer`) and **the packages**
  (`aequalyn-pkgs`) that turn it into a system you can boot.

These pages are built from the documentation in those repositories, so they describe what
the code does today. Every page links to the file it comes from: if something is wrong or
missing there, an issue or a pull request fixes it here too.
